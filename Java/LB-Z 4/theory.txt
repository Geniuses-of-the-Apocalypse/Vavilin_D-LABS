=== НЕМНОГО ТЕОРИИ ===
1. Компоратор - класс для сравнения объектов и задаёт правила сортировки.
2. Iterator - помогает последовательно перебирать элементы коллекции.
3. Inteface Comporator - встроенный в Java интерфейс, отдельное написание не требуется.
4. Для каждого типа данных пишем свой компоратор, для работы с большим количеством классов.
